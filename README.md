# AppBoost - Expo React Native Starter Template 👋

The complete Expo React Native starter template with everything you need to ship your mobile app faster. Free and open source under the [MIT license](LICENSE).

```bash
git clone https://github.com/samyost1/AppBoost.git my-app
cd my-app
npm install
```

Then follow [Getting Started](https://appboost.dev/docs), or open the project in Claude Code and run `/appboost`.

## Features

- 💳 **Payments** - RevenueCat integration with pre-built paywall
- 📱 **Push Notifications** - Expo notifications with token management
- 🗄️ **Backend** - Supabase integration for auth, database, and real-time
- 🎨 **UI Components** - Library of pre-built, customizable components
- 🎯 **Pre-Built UI Screens** - Ready-to-use screens for common app flows
- 🌗 **Dark Mode** - Built-in light and dark theme support
